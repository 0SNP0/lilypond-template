# LilyPond code style

## Номера тактов и навигация

Музыкальные исходники расположены в `music/*.ily`. Соглашение: **один такт на строку** и комментарий с номерами перед каждым блоком из четырёх тактов. Например:

```lilypond
fluteOneMusic = \relative c'' {
  % Bars 1–4
  c4 e g e |
  f4 a g2 |
  e4 d c2 |
  d2 r2 |
  % Bars 5–8
  e4 g c b |
  a4 g e2 |
  f4 e d b |
  c1\bar "|."
}
```

В длинных произведениях продолжайте нумерацию: `% Bars 9–12`, `% Bars 13–16` и далее. Комментарии должны соответствовать **реальным** номерам тактов во всех инструментах, в том числе после изменения структуры, добавления затакта или репризы. Если форматируете по два такта на строку, оставляйте столь же понятные ориентиры; нумерация должна совпадать между инструментами.

Комментарии предназначены для редакторов (Frescobaldi, VS Code). Они не печатаются в PDF и не влияют на MIDI. Команды `\partCombineApart` и `\partCombineUnisono` управляют исключительно совместной записью. Не меняйте ноты второй партии ради искусственного объединения.

## Другие правила

- У каждого инструмента собственный файл `music/<instrument>.ily`; ноты записываются в концертном строе.
- Порядок инструментов определяет `orchestra.ily`, а не номерные префиксы имён файлов.
- Не дублируйте музыку в файлах `parts/*.ly`: они подключают готовые музыкальные переменные.
- В `metadata.ily` хранятся полное название произведения и отдельное короткое имя для экспорта.
