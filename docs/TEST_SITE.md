# Сайт этой партитуры

Сайт публикуется по адресу
https://0snp0.github.io/lilypond-template/ , просмотрщик —
https://0snp0.github.io/lilypond-template/viewer/ .

**Один репозиторий партитуры — один сайт.** В `site/index.html`
лежит главная страница, в `scorekit/viewer/portal/` — общий
просмотрщик. Центрального `catalog.json` здесь больше нет.

Сайт использует **только последний опубликованный GitHub Release**
(см. [Releases](https://github.com/0SNP0/lilypond-template/releases)).
В интерфейсе нет выбора репозитория и исторических тегов. Тег,
название и README берутся из готовых данных релиза. Графика SVG
и индивидуальные MP3 публикуются в виде статических файлов на
этом же Pages-домене, без междоменного `fetch` с GitHub Releases.

При выпуске релиза ScoreKit отправляет GitHub `repository_dispatch`;
`.github/workflows/pages.yml` обновляет Pages и перезаписывает
последний комплект. Изменения `site/` и `scorekit/viewer/` в
`main` также переиздают текущий последний релиз. Из-за предела Pages
скрипт ограничен 650 МиБ; при превышении выдаёт ошибку.

Локальный запуск прямо из каталога ScoreKit:

```bash
python3 scorekit/viewer/serve.py
```

Для просмотра свежего опубликованного комплекта из GitHub:

```bash
python3 scorekit/viewer/serve.py --from-release
```

Нужен установленный GitHub CLI (`gh`) и сетевой доступ к релизу.
Для локальных файлов без `gh` можно собрать аудио и SVG в
`dist/`, после чего простой запуск использует эти данные.

Внешний каталог сайтов произведений, если понадобится, будет
отдельным проектом со ссылками на эти Pages-сайты, а не каталогом
репозиториев внутри ScoreKit.
