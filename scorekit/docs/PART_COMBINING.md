# Объединение двух индивидуальных партий

Каждый исполнитель должен иметь отдельный редактируемый `music/<instrument>.ily`. В партитуре общая нотная строка формируется через LilyPond `\partCombine` из двух исходников. Аналогичная печатная обёртка может существовать в `parts/combined/`. Индивидуальные партии `parts/*.ly` при этом всегда доступны независимо.

Не копируйте одну и ту же музыку в файл объединённой пары. `\partCombineApart` и `\partCombineUnisono` используйте лишь при необходимости после проверки конкретных тактов. Если в исходниках уже имеются текстовые метки `I`, `II`, `a2`, автоматические подписи `printPartCombineTexts` могут создавать дубликаты — регулируйте их в печатном контексте.

Для ударных возможен отдельный *печатный* один голос с аккордами одновременных атак, при сохранении независимых MIDI-источников. Для такого проекта используйте `scorekit/scripts/merge_percussion.py`; алгоритм рассчитан на простые ритмические записи, неподдерживаемые конструкции должны вызывать ошибку, а не искажать звук.
