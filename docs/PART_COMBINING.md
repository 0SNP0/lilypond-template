# Объединённые станы: только целые такты и ручное управление

В общей партитуре и совмещённых партиях Flutes I–II, Clarinets I–II,
Trumpets I–II, Trombones I–II используется LilyPond `\partCombine`.
Исходники каждого музыканта находятся в `music/*.ily` и не дублируются.

## По умолчанию: раздельные голоса

Файл `music/paired.ily` включает `\partCombineApart` перед
музыкой каждого первого исполнителя. Поэтому один совпавший звук **не**
превращается в единый штиль и не вызывает надпись `a2`.
Весь такт остаётся записанным двумя независимыми голосами.

## Как вручную объединить целый такт

Если оба исполнителя играют **весь такт одинаково** (совпадают высоты,
длительности и паузы), можно поставить `\partCombineUnisono`
непосредственно перед первым звуком этого такта в файле первого
исполнителя, например, в `music/flute-1.ily`:

```lilypond
fluteOneMusic = \relative c'' {
  c4 e g e |                  % такт 1: два голоса
  f4 a g2 |                  % такт 2: два голоса
  \partCombineUnisono e4 d c2 |  % такт 3: a2, ЕСЛИ II играет то же
  \partCombineApart d2 r2 |     % такт 4: вновь два голоса
}
```

Этот фрагмент **иллюстративный**: в текущем этюде такт 3 второй флейты
другой, поэтому в рабочую партитуру данная пометка не добавлена.

Команды распространяются на последующие события вплоть до следующей
смены режима. Нужный возврат к раздельным голосам обозначается
`\partCombineApart` в **начале следующего такта**. Не принуждайте
унисон при несовпадающих ритмах, нотах или артикуляциях: принудительный
режим может скрыть отличающуюся партию.

Команда `\partCombineAutomatic` включает стандартное поведение
LilyPond, но может поставить `a2` над одной совпавшей нотой;
для обычной оркестровой вёрстки в этом проекте она не рекомендуется.

## Почему изменения доступны в предпросмотре

Пометка добавляется в обычный нотный файл первого музыканта. В
`score.ly` и совмещённом PDF её видит `\partCombine`, а
отдельная партия музыканта продолжает печататься самостоятельно.
Никаких предварительных генерирующих скриптов для Frescobaldi или
VS Code не требуется.

Автоматического распознавания целиком совпадающих тактов **пока нет**.
Предполагается, что аранжировщик явно подтверждает такие такты; это
помогает не выдавать ошибочно частичный унисон за совместное исполнение.

См. [LilyPond, Automatic part combining](https://lilypond.org/doc/v2.26/Documentation/notation/multiple-voices.html).


## Совпадающие паузы

На каждом из четырёх общих станов включён штатный `Merge_rests_engraver` LilyPond. Совместимые одновременные паузы отображаются одной паузой независимо от ручного режима `\partCombineApart`/`\partCombineUnisono`. Эта настройка **не объединяет отдельные совпавшие ноты** и не добавляет `a2`. Для много-тактовых пауз (`R`) LilyPond может требовать отдельной ручной корректировки, в отличие от обычных пауз (`r`).
