# ScoreKit Viewer — сайт одной партитуры

**Каждый репозиторий партитуры публикует свой GitHub Pages-сайт.**
ScoreKit содержит HTML/JS-движок, генератор сайта и скрипт подготовки
ресурсов. Фреймворк остаётся переиспользуемым, без сведений о конкретном
произведении; состав, ноты, метаданные, оформление главной страницы
(`site/`) и собственный минимальный GitHub Actions workflow принадлежат
репозиторию произведения.

## Последний релиз

При выпуске Git-тега `v*` сборка ScoreKit публикует в GitHub Releases
индивидуальные PDF, архив PDF, общий MP3, MP3-архив и SVG/JSON-архив.
После завершения релиза отправляется событие `scorekit-release`,
которое запускает Pages-сборку.

```bash
python3 scorekit/viewer/build_site.py --output _site
python3 scorekit/viewer/publish_latest.py --output _site --repo OWNER/REPO
```

Скрипт `publish_latest.py` скачивает **только последний опубликованный
релиз**, проверяет имена/размеры файлов, извлекает из архивов SVG, JSON
и MP3 в `_site/viewer/latest/`, проверяет полноту ссылок и формирует
`_site/viewer/latest.json`. Нужны Python 3 и GitHub CLI (`gh`) с
чтением репозитория. В Actions аутентификация через `GH_TOKEN`.
Ограничение размера сайта по умолчанию — 650 МиБ; если комплект больше,
сборка останавливается, а не публикует неполный сайт.

Нет выбора репозитория или версии. Пользователь видит только текущий
публичный релиз: выбор нот (общая, концертная, индивидуальная и
объединённая партия), выбор аудиодорожки, масштаб SVG, положение такта,
README релиза и ссылку на GitHub Releases с PDF. Файлы передаются с
**того же домена Pages**, поэтому для них не требуется CORS. SVG
подгружаются по страницам с `loading="lazy"`; MP3 только при выборе
дорожки и по мере воспроизведения.

GitHub Releases остаётся архивом исторических версий, но Pages
не хранит старые комплекты. Обновление главной страницы происходит
автоматически из `viewer/latest.json`.

## Локальный запуск из ScoreKit

```bash
python3 scorekit/viewer/serve.py
```

Используются уже собранные локальные `dist/viewer/` и `dist/audio/`,
если они есть. Чтобы скачать текущий релиз и посмотреть его локально:

```bash
python3 scorekit/viewer/serve.py --from-release
```

В браузере откроется `http://127.0.0.1:8000/viewer/`. Можно
передать `--port 8080` и `--no-browser`.
Локальная схема URL идентична Pages.

## Будущий внешний каталог

Внешний каталог — **отдельный статический сайт со ссылками на сайты
произведений**. Он не загружает все SVG/MP3, не служит хранилищем
партитур и не обязан подключать ScoreKit как сабмодуль. Если понадобится
центральный каталог, его можно реализовать независимо от фреймворка.

Будущий отдельный репозиторий ScoreKit подключается в каждом проекте
как Git-сабмодуль по пути `scorekit/`. Сейчас ScoreKit остаётся
обычным каталогом этого репозитория.
