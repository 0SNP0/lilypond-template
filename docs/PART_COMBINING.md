# Совмещённые партии без дублирования исходных нот

**Редактировать только** `music/flute-1.ily`, `music/flute-2.ily` и аналогичные **индивидуальные** музыкальные файлы. Девять ранее существовавших файлов `music/*-1-2.ily`, `music/horns-1-3.ily` и подобных удалены.

Файл `music/paired.ily` содержит лишь `\\partCombine` для двух исходных голосов: одна пара на одном стане в оркестровой партитуре и в `parts/combined/`. Файлы `parts/*.ly` сами не содержат нот. Общие репетиционные метки берутся из `music/global.ily`.

`\\partCombine` автоматически определяет варианты одинаковых и независимых голосов; при неоднозначности вручную расставляйте `\\partCombineApart` и `\\partCombineUnisono` в исходной партии **только после сверки**. Для разделения целотактовой паузы и нот другого инструмента пользуйтесь `\\once \\override MultiMeasureRest.staff-position` в исходном голосе. Знаки динамики обоих музыкантов хранятся в их индивидуальных партиях; дублирующих надписей в отдельном общем нотном файле нет.

Ударные: `music/percussion.ily` собирает три голоса (`snare-drum.ily`, `cymbals.ily`, `bass-drum.ily`) на одном `DrumStaff`, без копирования нот. Для редактирования достаточно изменить соответствующий ритмический голос.

## Автоматические надписи `Solo`/`a2`

Объединение выполняется через `\\partCombine`, но автоматические слова `Solo I/II` и `a2` отключены свойством `printPartCombineTexts = ##f`: иначе они дублировали исходные пометки `I`, `II` и `a2` из нотных файлов. Для ручного обозначения унисона используйте явную пометку в исходном голосе. Существующие ноты и исполнительские маркировки от этого не удаляются.
