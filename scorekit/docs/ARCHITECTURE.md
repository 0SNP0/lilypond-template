# Разделение произведения и ScoreKit

**Каталог `scorekit/` пока обычная отслеживаемая Git-папка**, а не сабмодуль. Все новые улучшения сборки вносятся внутрь неё, чтобы позднее вынести папку в самостоятельный репозиторий без изменений в путях.

## Ответственность проекта партитуры

- `music/*.ily`, `music/playback-map.json`: собственно нотный материал, специальные проверки и порядок воспроизведения;
- `orchestra.ily`, `score.ly`, `concert-score.ly`, `parts/*.ly`: состав оркестра, контексты, нотационная транспозиция, индивидуальные партии и объединённые рабочие места;
- `metadata.ily`: название, композитор, оркестр, выходной префикс, имена переменных, специфичная форма playback;
- `.github/workflows/build.yml`: базовые события GitHub (`push`, `pull_request`, ручной экспорт и тег релиза), разрешения и вызов локальных ScoreKit actions;
- `docs/`: только редакционные сведения, характерные для произведения;
- `build/`, `dist/`, `soundfonts/*.sf3`: временные/производные данные репозитория, не содержимое ScoreKit.

## Ответственность ScoreKit

- `scripts/`: сборка, проверки структуры, навигация, генерация ударного голоса, MIDI/аудио/SVG-экспорт, независимые хеши исходников и печати;
- `actions/build/` и `actions/release/`: все универсальные CI/CD-шаги, включая установку зависимостей, архивирование артефактов и публикацию;
- `lilypond/layout/` и `lilypond/version.ily`: A4, заголовки, система страниц, колонтитулы и Git-версия;
- `viewer/`: универсальный интерактивный SVG/аудио-просмотрщик; заголовок берётся из `metadata.ily`;
- `docs/`: общие инструкции и правила организации исходников.

## Подготовка к сабмодулю

Имя и URL отдельного репозитория пока не определены. При будущем выделении сохранить путь **`scorekit/`**; потребуется создать отдельный репозиторий с содержимым этой папки, заменить её gitlink на выбранный commit и добавить `.gitmodules`. Путь вызова `./scorekit/actions/build` при этом останется тем же.

В базовом `.github/workflows/build.yml` checkout уже использует `submodules: recursive`; для приватного подмодуля также должны быть корректно настроены права на его чтение. Скрипты вычисляют корень партитуры как родительский каталог ScoreKit и потому не зависят от имени репозитория произведения.

Временные зависимости и данные произведения не должны копироваться в отдельный будущий репозиторий ScoreKit.
