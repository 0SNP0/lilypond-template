# Общие правила LilyPond-исходников

- Каждый исполнитель редактируется в собственном `music/<instrument>.ily`. Общие `orchestra.ily` и `music/global.ily` определяют порядок станов, размерность и репетиционные ориентиры для данного произведения.
- В `parts/*.ly` хранятся ссылки, ключи, нотационная транспозиция и оформление, **без дублирования нот**. Для пар — `parts/combined/*.ly` и `\partCombine`.
- Комментарии с номерами тактов не влияют на PDF/MIDI, но обязаны совпадать с фактическими границами; `R2.*N` допустим для длинных пауз.
- Печатный и звучащий строй задавайте осознанно: нельзя предполагать одинаковые правила транспонирования для разных произведений.
- Метаданные в `metadata.ily` должны задавать отдельное компактное имя файла (`workFileSlug`) и печатные заголовки. Общие элементы оформления — только в ScoreKit.
- Исполнительские динамические и текстовые пометки хранятся рядом с музыкальными событиями; отступы, размер стана, заголовки и шрифты — в коде оформления.
