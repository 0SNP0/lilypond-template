# ScoreKit Viewer — локальный просмотр и будущий GitHub Pages

Это универсальная статическая страница, не привязанная к отдельному произведению.
Файлы сайта находятся в `scorekit/viewer/portal/`:

- `index.html`, `app.js` — выбор репозитория, опубликованного релиза, печатной партии и MP3-дорожки, масштабируемые SVG-страницы, номера тактов во время воспроизведения;
- `catalog.json` — необязательный массив ссылок на GitHub-репозитории; **пока `[]`**;
- используемый в сборочных релизах формат — `*-viewer-*.zip` с `viewer/manifest.json`, `viewer/timeline.json`, `viewer/svg/*` и отдельный `*-audio-*.zip`.

## Самый простой локальный запуск

Из корня репозитория:

```bash
python3 scorekit/viewer/serve.py
```

Команда запускает локальный HTTP-сервер и открывает браузер по адресу
`http://127.0.0.1:8000/`. Можно запустить и без отдельного скрипта:

```bash
python3 -m http.server 8000 --bind 127.0.0.1 --directory scorekit/viewer/portal
```

## Как посмотреть SVG уже сейчас (без публичного репозитория)

1. Откройте в GitHub Actions успешный запуск сборки в ветке партитуры.
2. Скачайте `score-media-<SHA>` из раздела Artifacts.
3. Откройте локальный просмотрщик, нажмите **SVG/JSON ZIP** и выберите скачанный архив *целиком*. Он содержит `viewer/manifest.json`, `viewer/timeline.json` и SVG; отдельная распаковка не требуется.
4. Выберите `score` или нужную партию; появятся **настоящие страницы LilyPond в SVG**. Каждая страница дополнительно доступна по ссылке «SVG · страница N» для отдельного открытия.
5. Для прослушивания в поле **MP3 ZIP** можно указать тот же Actions-артефакт (в нём есть `audio/`) либо скачать `*-audio-*.zip` из релиза и указать его. Аудио читается только после выбора дорожки.

Альтернатива: скачайте `*-viewer-*.zip` из GitHub Release и укажите его
в поле SVG/JSON. Для приватного репозитория этот путь работает без авторизации
GitHub API, поскольку файл уже находится на вашем компьютере.

Приложение также умеет через публичный GitHub REST API открывать репозиторий
`owner/repo`, получать список его Releases, загружать архив версии и
показывать README по выбранному тегу. **Важная проверка перед публикацией:**
скачивание ZIP по `browser_download_url` из JS на другом домене может
блокироваться CORS. В этом случае используйте скачанный ZIP локально; для
публичного сервиса потребуется разрешённая CORS-доставка или отдельные статические
URL. Приватный GitHub API без авторизации браузеру недоступен.

При выборе партии SVG распаковываются и отображаются как изображения
(это исключает исполнение встроенного в SVG кода); никаких сборочных
операций на сервере нет. Аудиоархив не скачивается заранее, но при выборе
дорожки ZIP загружается целиком и только затем браузер извлекает нужный MP3.

## GitHub Pages без размещения в корне

Каталог `portal/` **самодостаточен**: использует только относительные пути
`./app.js`, `./catalog.json`. При переносе в отдельный Pages-репозиторий
достаточно положить его содержимое в папку `viewer/`. Тогда в
пользовательском сайте путь будет `https://OWNER.github.io/viewer/`,
а в проектном сайте `https://OWNER.github.io/REPOSITORY/viewer/`.
В корне можно разместить любую другую домашнюю страницу, документацию и ссылки.

GitHub Pages позволяет один пользовательский сайт для аккаунта, но
отдельный project Pages-сайт может быть у каждого репозитория. Публикация
Pages сейчас **не включена** и приватные данные автоматически не раскрываются.

Подключена библиотека JSZip из публичного CDN (требуется интернет).
